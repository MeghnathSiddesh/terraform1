Difference between bucket and bucket_prefix

Using bucket:
resource "aws_s3_bucket" "secure_bucket" {
  bucket = "my-company-audit-logs-bucket"
}

Terraform creates a bucket with that exact name, provided it is available.

Using bucket_prefix:
resource "aws_s3_bucket" "secure_bucket" {
  bucket_prefix = "my-company-audit-logs-"
}

Terraform generates a unique bucket name starting with that prefix, such as:
my-company-audit-logs-a1b2c3d4
